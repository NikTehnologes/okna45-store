# okna45-store

Подготовленный статический каталог **Okna45**. Сам по себе этот каталог ещё не создан и не опубликован на GitHub.

## Ручная публикация

1. Создайте **отдельный публичный** репозиторий `okna45-store` в своём GitHub-аккаунте.
2. Вручную загрузите **содержимое этой папки**, сохранив структуру `docs/`, а не внешний каталог `github_store/`. Можно через Git или загрузку папок в веб-интерфейсе. Ключи, `wifi.json`, заметки и пользовательский flash загружать не нужно.
3. В **Settings → Pages**: Source **Deploy from a branch**, Branch **main**, Folder **/docs**, Save. Actions для записи и токены Pico не нужны.
4. Дождитесь успешного Pages deployment. Обычный адрес проекта: `https://ВАШ_АККАУНТ.github.io/okna45-store/`; используйте фактический адрес из Settings → Pages.
5. В ОС: **Store → Setup** → адрес сайта → **Save → Check**. Store только скачивает данные и не имеет доступа на запись в GitHub.

Если Pages недоступен по выбранному плану/политике аккаунта, эти же файлы `docs/` работают на обычном статическом HTTP(S)-хостинге. На физическом Pico HTTPS/heap требуют проверки; не считайте успешную сборку проверкой устройства.

## Новые приложения и обновления

Подготовка выполняется в основном проекте Okna45 на компьютере:

```powershell
python -B tools/build_store.py
python -B tools/publish.py myscript.py --name myscript --version 1.0.0
python -B tools/publish.py updates/0.2.0/calculator-1.0.0.sin
python -B tools/publish.py updates/0.2.0/okna45-system-0.2.0.sin --os
```

`tools/publish.py` теперь **только локальный сборщик**: он не делает HTTP-запросов, не использует токены, не выполняет Python приложения. Для другой папки используйте `--output ПУТЬ`. Затем вручную загрузите изменённые файлы репозитория в GitHub и дождитесь Pages deployment.

- `catalog.json` — локальное состояние/версии, без секретов; сохраняйте его для следующей сборки.
- `docs/index.json` — приложения; `docs/updates.json` — отдельные system/software каналы.
- `docs/blobs/` — неизменяемые файлы по SHA256. Не удаляйте старые blobs: клиент мог закешировать прежний каталог.
- `docs/packages/` — готовые app SIN; `docs/downloads/` — первый bootstrap/full releases.
- Не меняйте уже опубликованную версию: сначала увеличьте `major.minor.patch`. Первый полный переход требует обоих каналов; на небольшом flash лучше скачивать и применять **по одному**.

Это личный каталог доверенных авторов. SHA256 обнаруживает повреждение, **не подтверждает автора**; Python-приложения имеют те же права, что и ОС.
