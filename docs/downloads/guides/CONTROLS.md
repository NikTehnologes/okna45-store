# Управление Okna45 — CardKB

**Okna45 0.2.6**, обновлено 25 ноября 2026. Установка/ремонт: [GUI_OS_026.md](GUI_OS_026.md).

CardKB передаёт готовый символ или код служебной клавиши. **Сочетаний Ctrl/Alt/Shift в управлении ОС нет.** Заглавные буквы и спецсимволы вводятся как обычные символы, не как команды.

## Запуск

После reset идут пять циклов RGB332-заставки (9,7 секунды плюс инициализация/первый экран), затем desktop. Команда `desktop` для обычного запуска не нужна. В браузерной панели нажмите на экран для подключения клавиатуры; PicoTerm постоянно в RAM не создаётся.

Браузерный клик только подключает клавиатуру: элементы гостевой ОС нажимаются **указателем и Enter**, а не мышью компьютера. Держите фокус на экране, не в поле команды браузера.

## Два режима

| Клавиша | Режим указателя — после запуска | Режим ввода в окно |
|---|---|---|
| Стрелки | Двигают указатель на 8 пикселей | Передаются приложению: текстовый курсор или выбор строки |
| Enter | Нажать элемент под **остриём** указателя | Новая строка в Notes / команда в Console / открытие в Files |
| Tab | Включить ввод в активное окно | Вернуть указатель |
| Esc | Открыть/закрыть Start; отменить открытый диалог | Вернуть указатель, не выходя из рабочего стола |
| Буквы, цифры, спецсимволы | Игнорируются; `~` открывает Start | Обычный ввод, включая заглавные буквы и `~` |

Верхняя строка напоминает режим: **Tab Input**, **Tab Point** или **Enter Drop**. При вводе указатель скрывается; положение сохраняется. Tab **не переключает окна** и не вставляет символ табуляции в заметку.

## Окна и Start

Любое «нажатие» ниже: наведите указатель стрелками и нажмите **Enter**.

- **Start** внизу слева — открыть меню. Выберите вкладку и плитку указателем/Enter. `~` в режиме указателя открывает/закрывает меню; Esc закрывает его. Нажатие вне меню только закрывает его, без нажатия скрытого окна.
- Вкладки **Tools** (Welcome, Notes, Console, Files, Clock, Run), **System** (Monitor, Tasks, Packages, Store), **Network** (WiFi), **Games** (Cube), **Apps** (установленные программы). Установленные приложения могут выбирать и Tools/System; до 6 плиток/страницу; **< / >** переключают страницы. **Console** открывает графическую консоль, Restart перезагружает после подтверждений.
- Установленные apt/SIN-программы получают значки на desktop (первые 12) и плитки Start (все). Оконная программа открывает API-окно; terminal/script открывает текстовое окно, не выгружая desktop. Full/Gfx — отдельная необязательная compatibility. Несохранённые Notes требуют подтверждения перед maintenance/reset.
- Нажатие на окно или его кнопку в панели задач — вывести на передний план. Кнопка панели задач также **восстанавливает свёрнутое окно**.
- **`_`** в заголовке — свернуть. **`X`** — закрыть.
- Нажатие на **текст заголовка** — взять окно для переноса. Стрелки двигают окно вместе с указателем; **Enter** ставит его. Esc или Tab также заканчивают перенос, оставляя новое положение.
- Нажатие в области текста Notes или Console включает ввод; есть и кнопка **Input**.
- Большинство приложений при повторном запуске фокусирует существующее окно; Notes может иметь несколько окон. Лимит сейчас 2–4 окна по оценке свободной памяти.

## Приложения

### Notes

- Нажмите **Input** или Tab; печатайте ASCII-текст. Enter — новая строка; стрелки — текстовый курсор; Backspace / Delete — удалить слева.
- Курсор — вертикальная черта 2×10: мигает при вводе, остаётся серым в режиме указателя у активной заметки. При движении/вводе показывается сразу; длинные строки и страницы прокручиваются.
- Для сохранения верните указатель через Tab и нажмите **Save**. Нажатие в тексте ставит текстовый курсор и включает ввод.
- **New**: введите `/scripts/name.py` или `/documents/name.txt`, Enter; Save создаёт файл, в том числе пустой. **Open** открывает существующий путь, **Save As** сохраняет копию. В диалоге пути Tab переключает ввод/указатель, Esc отменяет; готовые Y/N там являются буквами имени, не ответами закрытия.
- **Run** сохраняет `.py` и запускает: простой скрипт/`run(term,args)` создаёт текстовое окно с print/input, прокруткой и Stop/Again; `Main(Application)` — API-окно. Свёрнутое окно продолжает выполнение, close отменяет cooperative tasks и освобождает код. Код/отступы набирайте ASCII/пробелами; Tab остаётся режимом ОС.
- При закрытии изменённой заметки появляется **Save changes?**: **Save** — сохранить и закрыть, **Discard** — закрыть без записи, **Cancel** — остаться. Эти кнопки работают стрелками и Enter.
- В этом диалоге можно вместо кнопки отправить готовый символ **Y/y** или **N/n**, без Enter; **Esc** отменяет закрытие **и выход из рабочего стола**. При ошибке записи диалог остаётся открытым.
- Пользовательские Python-файлы редактируются; системные `.py`, `/system/`, `/repo/`, `/apps/`, `.mpy`/`.sin` и неподдерживаемый текст — только просмотр. Создание/Save As не затирают существующий другой файл: откройте его явно.

### Run и Store

- **Run**: поле принимает ID приложения, `/scripts/name.py [args]` или команду. Enter/кнопка Run запускает; **Auto / Win / Text / Full** выбирает тип. **Edit** открывает путь в Notes. Full требует optional legacy files, которых нет в минимальном flash.
- **Store** по умолчанию использует `https://niktehnologes.github.io/okna45-store`: сразу **Apps → Check**, без ввода URL. **Setup → Server → Save** нужен для смены адреса; старые сохранённые настройки имеют приоритет. Поля ключа нет, Store только читает.
- **Apps**: выбрать строку, **Get** установить/обновить, **All** обновить установленные, **Del** удалить, **^ / v** прокрутить.
- **OS**: **Check → Sys или Soft → Apply**. Каналы отдельно, проверяется SIN/staging. Apply подтверждается, выгружает desktop/reset. **Stop** отменяет download. **С 0.2.4/старше на текущую 0.2.6 нужен новый host updater/bootstrap**, старый Store не знает `.oba`. Установленная 0.2.5 принимает system 0.2.6 штатно; software source прежний, full SIN новой версии синхронизирует baseline.
- Вкладки Store: **Apps / OS / Setup**. Запись в GitHub — вручную с компьютера; локальная подготовка каталога: [`STORE.md`](STORE.md).
- В 0.2.3 **Apps → Check** скачивает только каталог приложений, **OS → Check** — только каталог ОС; **Setup → Check** проверяет оба последовательно. Списки отпускаются перед сетевым заданием и восстанавливаются после него; пока оно идёт, вкладки заблокированы. Закрытие Store отменяет активное задание.
- Новые отдельные приложения и их CardKB-клавиши: **[сначала установка/публикация, затем Checklist/Pong/Tetris/Mines/Flappy](STORE_APPS.md)**. В играх сначала включите **Input через Tab**; Pong/Tetris/Flappy начинают на паузе, Сапёр — без таймера. Сворачивание не ставит игру на паузу автоматически.
- **[Следующие приложения: AI, Messenger v2 и затем Snake](NETWORK_APPS.md)**. AI: Tab → текст → Enter/Send; выбор LLM7/Pollinations ручной. Messenger: My ID → Add UUID друга → Open; открытый чат сразу опрашивается **500 мс**, Pause отключает новые опросы, Live возобновляет, Sync проверяет сейчас. Enter отправляет текст; во время получения можно печатать, во время отправки — дождитесь завершения. Свёрнутый чат продолжает опрос. Snake: стрелки/WASD, Enter/Space/P — пауза, R — New; начинает на паузе.

### Files

- Указателем выберите строку, затем нажмите **Open**. Кнопки **Up** — родительская папка, **Load** — обновление, **^ / v** — выбор предыдущей/следующей строки и прокрутка.
- **Open** входит в папку, показывает поддерживаемый текст в Notes или обрабатывает `.sin`; **Run** отдельно запускает `.py`. Большой/неподдерживаемый файл не превращается в пустую заметку; ошибка видна в окне.
- В режиме ввода: ↑/↓ — выбор, Enter — открыть, Backspace / Delete — родительская папка, готовая буква **R/r** — обновить.

### Clock

- **Zone** циклически выбирает UTC / Moscow / Yekaterinburg / Kolkata / Kathmandu / Tokyo и фиксированные UTC-offset presets.
- **-15m / +15m** меняют смещение; **Sync** вызывает NTP после подключения Wi‑Fi. Ошибка показывается в окне.
- Настройка сохраняется в `/system/timezone.json`. RTC остаётся **UTC**, автоматического перехода DST нет. Команда `timezone +05:45` задаёт точное смещение; диапазон −12:00…+14:00.

### WiFi

1. Start → Network → WiFi. **Scan** получает сети; выберите строку указателем или ↑/↓ в input mode.
2. Нажмите поле **SSID** или **Key** и введите текст. Пароль на экране скрыт. Backspace/Delete удаляют слева; Enter из SSID выбирает пароль, из пароля возвращает указатель; Tab тоже возвращает указатель.
3. **Save** сохраняет `/wifi.json`, **Link** подключает, **Off** отключает. Save и Link отдельные: подключение не сохраняет пароль автоматически.

Статус показывает подключение, IP/ошибку/тайм-аут. Закрытие во время подключения отменяет его; уже установленное соединение остаётся. `scan()` драйвера блокирующий, association опрашивается кооперативно. В эмуляторе Wi‑Fi **симулируется**, а не подключает Windows к сети. Пароль скрыт в `/desktop`, но конфигурация на flash и read-only file API не шифруются.

### Tasks и System monitor

- В Tasks выберите строку указателем. **Pause / Resume** — приостановить/продолжить, **Cancel** — отменить задачу. **^ / v** — выбор и прокрутка.
- В режиме ввода: ↑/↓ — выбор, **P/p** — пауза/продолжение, Backspace / Delete — отмена.
- Службы клавиатуры, часов и отрисовки защищены; их кнопки неактивны. Отмена задачи не равна закрытию её окна.
- В System monitor кнопка **Tasks** открывает диспетчер. Задачи **кооперативные**, а не вытесняющие потоки: выполняемый код должен уступать управление.

### Cube

**Pause / Resume** — остановить/продолжить вращение. В режиме ввода то же делает Space. Верните указатель через Tab, чтобы работать с другими окнами; куб продолжает работать в фоне.

### Console и Packages

Нажмите **Input** или Tab, затем команду и Enter. Backspace / Delete удаляет слева. Для экранных кнопок вернитесь через Tab; **Clear** очищает вывод.

**^ / v** листают вывод на строку; **End** возвращает свежий вывод. В input mode ↑/↓ — строка, ←/→ — страница. Прокрутка работает во время задания; набранная команда сохраняется. История ограничена 64 строками и 8192 bytes.

```text
help
open notes
open notes /my-note.txt
open files
open monitor
open run_app
open store
run /scripts/myapp.py
ps
kill ID
echo Hello
clear
exit
```

`kill ID` отменяет пользовательскую задачу, кроме текущего окна консоли. `run /file.py` создаёт текстовое окно, обычные module commands направляются в GUI. Tab/Esc не возвращают оболочку. Произвольный CPU loop/blocking sleep/socket не прерываются Stop: tasks кооперативные.

Менеджер пакетов работает в графической Console/Packages:

```text
apt update
apt search hello
apt show hello
apt install hello
apt install counter
install /counter-1.0.0.sin
apt list
apt upgrade
apt remove hello
apt source
```

Default source — Pages `/index.json`; `/repo/index.json` работает лишь если пользователь отдельно сохранил такой repo. Он не входит в OS flash. Counter — API-окно, Hello — text window. SHA256 — целостность, **не подлинность**. API: [`DEVELOPER_API.md`](DEVELOPER_API.md).

Системные/встроенные обновления — Store → OS либо `update /release.sin` с подтверждённым выходом в maintenance, затем reboot. `updates check`, `updates download system`/`software`, `updates apply` работают со статическим сайтом; установка core не идёт одновременно с desktop. Переход со старого flash: [`UPDATES.md`](UPDATES.md). `apt update` обновляет лишь индекс, не ОС.

## Необязательная legacy-совместимость и браузер

- PicoTerm/старые fullscreen sources сохранены вне минимального runtime, но обычный boot их не импортирует. Следующие два пункта относятся только к явно установленной legacy-совместимости.
- У приглашения PicoTerm/`input_line`: ↑/↓ листают текст по строке, ←/→ по странице. Сохраняются 64 ушедших ряда; буква/Enter/Backspace/Esc возвращают текущую строку без потери набранного. Clear очищает историю; старые ряды монохромные. В legacy-приложениях с сырым `readkey()` стрелки остаются их управлением.
- Старый редактор `edit` сохраняет своё управление **hjkl**; на его вопрос `Save?` ответьте `y` или `n` **и нажмите Enter**.
- ↑/↓ в **поле команды браузера** выбирают историю, не двигают гостевой указатель. В рабочем столе перед отправкой текста через это поле или вставку включите режим ввода. Панель откажется посылать текст в режиме указателя, чтобы Enter случайно не нажал кнопку.

## LLM и скрипты

В рабочем столе используется `POST /api/v1/keys`, **не новая `/command`**. `GET /api/v1/desktop` сообщает `input_mode`, `pointer`, `pointer.target`, окна, `controls`, `menu.tabs/entries/controls`, `applications`, `icons`, timezone и задачи. Прямоугольники `[x,y,w,h]` — в **320×240**, не увеличенной картинке браузера.

Двигайте указатель служебными клавишами, затем Enter; прямой API-команды «нажать» или «выполнить действие» нет. После отправки дождитесь изменения модели; `keys_processed` считает **законченные обработки клавиш**, не только принятые байты очереди. Открытие рабочего стола ещё не означает готовность всего изображения: для снимка проверьте `renderer.pending == 0`.

```powershell
python -B ztest.py state --json
python -B ztest.py key ENTER --json
python -B ztest.py key UP UP UP UP UP UP UP UP UP UP UP UP UP UP UP UP UP UP UP --json
python -B ztest.py key RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT RIGHT --json
python -B ztest.py key ENTER --json
python -B ztest.py key TAB --json
python -B ztest.py text "Hello Okna45 ~!" --json
```

Пример открывает Notes из начального состояния: 19 ↑ и 17 → переводят указатель с `(24,224)` на `(160,72)` внутри плитки Notes вкладки Tools. Для другого состояния читайте свежие координаты. Save — Tab, затем наведение на кнопку из `content.controls`.

Коды: `ENTER=13`, `ESC=27`, `TAB=9`, `BACKSPACE=8`, `LEFT=180`, `UP=181`, `DOWN=182`, `RIGHT=183`. Символы `A`, `!`, `~` — их обычные ASCII-коды; никаких событий нажатия модификаторов нет.
