Сначала установка / обновление Okna45 0.2.6

  1. Сохраните Notes/черновики; закройте USB editors.
  2. Распакуйте ZIP папки ОС.
  3. Запустите Windows updater, выберите папку с os-files.json и Pico COM.
  4. Дождитесь backup и установки. repo/user data не копируются и не удаляются.

С 0.2.4 и старше нельзя переходить напрямую через старый Store: он не знает новый .oba. Альтернатива — актуальный USB bootstrap и оба full SIN без запуска main между ними. Recovery journals должны быть завершены заранее. Хостовая операция не атомарна при USB/power loss; backup нужен для restore.
