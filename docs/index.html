Installation first

OS folders, updater, Messenger EXE/APK and full SIN files. The host updater selects os-files.json, backs up changed OS files and preserves user files. repo is not uploaded to Pico. Migration from 0.2.4 or older requires the new host updater or USB bootstrap: the old Store allowlist does not accept the new OBA2 asset. Normal OS channels do not replace stable boot recovery.
